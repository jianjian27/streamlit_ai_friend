# AI Friend

这是一个基于 Streamlit 构建的本地 AI 聊天应用，支持与本地 Ollama 模型对话，并提供会话历史、最近聊天列表、人物设定和会话持久化等功能。

## 功能概览

- 与本地 Ollama 模型进行流式对话
- 自动保存当前会话内容，不需要手动点击“New Chat”才保存
- 提供 Recent Chats 历史列表，支持切换历史对话
- 当前会话高亮且不会被强制置顶，体验更接近常见 AI 聊天软件
- 支持自定义 AI 角色昵称与性格设定
- 仅保存有效会话，避免空会话和无意义草稿文件
- 自动维护最近会话数量，最多保留 50 个会话

## 项目结构

- `ai_friend.py`：主应用入口，包含 UI、会话逻辑、模型调用、保存/加载、历史列表等
- `ai_friend_session/`：会话 JSON 文件存放目录
- `image/`：界面图标/图片资源
- `audio/`、`video/`：其他相关资源目录
- `streamlit_learning.py`：学习/测试用脚本

## 运行前准备

1. 安装 Python 依赖

```bash
pip install streamlit
```

2. 安装并启动 Ollama

确保本机已安装 Ollama，并拉取所需模型：

```bash
ollama pull qwen2.5:3b
```

然后启动 Ollama 服务：

```bash
ollama serve
```

3. 确认模型可用

应用默认使用：

- API 地址：`http://127.0.0.1:11434/api/chat`
- 模型：`qwen2.5:3b`

如果你的本地配置不同，请在 `ai_friend.py` 中修改相关参数。

## 启动方式

在项目根目录执行：

```bash
streamlit run ai_friend.py
```

随后打开 Streamlit 自动生成的本地地址即可使用。

## 关键行为说明

### 1. 会话保存

当前会话会在用户输入后立即保存，不需要手动点击“New Chat”。

在以下场景中也会进行保存：

- 用户发送新消息
- 切换到另一条历史会话前
- 新建对话前

### 2. 历史会话列表

历史会话通过 `ai_friend_session` 下的 JSON 文件构建，按更新时间倒序展示。

当前逻辑中：

- 选中会话会高亮
- 不会因为点击选中而强制移到列表顶部
- 切换会话时，当前内容和高亮会同步更新

### 3. 默认角色信息

默认名称和个性定义在代码中：

```python
DEFAULT_NAME = "陈兆睿"
DEFAULT_PERSONALITY = "tough"
```

如果用户在界面中未填写昵称或人格描述，程序会使用这些默认值作为内部配置。

## 常见问题

### 1. 报错：连接 Ollama 失败

检查是否已运行：

```bash
ollama serve
```

并确认模型已下载：

```bash
ollama list
```

### 2. 历史会话不显示

可能原因：

- `ai_friend_session` 目录不存在
- 会话文件格式异常
- 会话中没有有效消息内容

重新启动应用即可重新扫描目录。

### 3. 删除会话后又出现新会话

如果删除的是当前会话，程序会将当前状态重置为新会话，并且不会重复写入空白会话文件。
